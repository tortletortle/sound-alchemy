## 目标 / 架构 / 运行方式

EchoAlchemy：本地实时声景视听实验。单文件 WebGL / Web Audio 原型，默认模拟声景。

运行：在仓库根目录执行 `python -m http.server 8000`，浏览器打开 `http://localhost:8000`。麦克风需要授权，远程部署需 HTTPS。

V0.2 开发改动：速度积分代替累计时间乘当前速度；着色器优先使用 highp。

验证：`node tests/travel.test.cjs`，覆盖 JS 语法、30/60/120 Hz 固定步长、零步长及速度阶跃。上述等价测试在 Node 22 本地通过；未验证 GPU 编译、实际帧率、真实麦克风、心理健康效果。

## V0.3：自适应声学前端

- 麦克风 RMS 动态估计底噪，1 秒初始化；不对原始音频进行上传。
- 使用相对增量、快速包络、滞回和 220 ms 不应期检测突发事件；FFT 中高频仍保留原映射。
- 合成特征验证：3 个帧率 × 3 个底噪 × 5 个随机种子，180/180 检出，0 误触发、0 漏检，最大采样检测延迟 22.33 ms；底噪台阶仅触发一次。
- 复现：`node tests/acoustics.test.cjs`。同一算法及基准已在 JavaScript 环境运行，远端测试文件逐字核验；尚未执行远端 Node 脚本本身和真实浏览器麦克风验收。
- 局限：以 RMS 为主，可能漏掉等能量音色变化、短于分析窗口的事件；持续声音突然升高可产生一次误触发。未做旧算法对照及真实录音验证，不能推断实际准确率或心理健康收益。

## V0.4：程序化光纱隧道

- 以 AI 生成视觉概念图为设计参考；使用程序化 GLSL 分层光纱、三层噪声、发光边缘、星尘、色彩映射和极简 HUD，不用静态概念图替代实时渲染。
- 保留 V0.3 自适应声学前端与 V0.2 位移积分。
- 验证：使用 Mesa EGL 软件 OpenGL ES 上下文编译顶点和片元着色器并链接，均通过；1000×600 单帧绘制和像素读取无 GL 错误。独立 GLSL 测试不代表浏览器验收。
- Chromium 测试未能初始化 WebGL 上下文，页面交互、真实音频联动和帧率仍待真实设备验收。实际着色器预览比概念图更稀疏、暗，仍需改进光纱细节和空间层次。

## V0.5：自适应程序化音乐引擎

- 替换固定四音正弦持续音，新增四声部和弦 Pad、低音根音、三角波短音符旋律、低通滤波与动态压缩。
- 使用 D Dorian 音阶与 Dm7 → G7 → Cmaj7 → Am7 和弦循环；旋律只从当前和弦音级抽取，主题切换移调至 D/E/G Dorian。
- 速度根据环境能量与中频特征自适应；低刺激模式将速度限制在较慢区间并降低总线增益。瞬态、高频和环境能量共同影响旋律事件概率与音区。
- 所有声音通过 Web Audio API 本地合成，必须由用户主动开启；不接入云端音乐模型，不上传麦克风数据。
- 增加 BPM HUD、和弦平滑切换、音符包络、压缩器与页面关闭清理。
- 算法模拟结果：平静输入稳定约 43.34 BPM，活跃输入约 74.30 BPM；30/60/120 Hz 三种调用频率在 60 秒内均产生 127 个节拍事件；固定输入和随机种子可复现，生成音符均落在所定义的 Dorian 音阶。
- 自动化脚本：`node tests/music.test.cjs`；与既有 `travel`、`acoustics` 测试一起运行。当前已提交测试源码，但尚未取得 GitHub Actions 或真实浏览器端的执行结果。
- 局限：这是规则驱动的程序化合成，不是扩散模型或神经网络作曲；尚未做听感盲测、音量安全测试、不同设备延迟与实际麦克风端到端验证。
